PC УГСРАГЧ — ТЕМПЕРАТУРЫН ХАРЬЦУУЛАЛТ

ФАЙЛУУД
- temp.html : Температурын харьцуулалтын веб хуудас
- temp.css  : Загвар, өнгө, responsive дизайн
- README.txt: Ашиглах заавар

ХАРЬЦУУЛАЛТЫН НӨХЦӨЛ
- Нягтрал: 1080p (1920×1080)
- График тохиргоо: High preset
- Ray Tracing: унтраалттай гэж үзсэн
- Өрөөний температурын жишиг: 22–25°C
- 7 төрлийн PC угсралт, тус бүр 6 тоглоомын CPU/GPU температурын жишээ
- Угсралт бүрийн мөрөнд 1080p · HIGH SETTINGS тэмдэглэгээ харагдана
- Угсралтыг нээхэд 1080p HIGH SETTINGS нөхцөлийг том, тод самбараар харуулна
- Хуудас нээгдэхэд 2 сая ₮ угсралтын хүснэгт эхэлж дэлгэгдэнэ; бусад угсралтыг дарж нээж/хаана

ЧУХАЛ ТАЙЛБАР
Хүснэгт дэх температурын тоонууд нь бодит төхөөрөмж дээр хэмжсэн benchmark биш, веб хуудасны харьцуулалтыг харуулах зориулалттай жишиг утгууд юм. Бодит температур нь CPU/GPU-ийн яг загвар, хөргүүр, кейсийн агаарын урсгал, сэнсний тохиргоо, өрөөний хэм, драйвер болон тоглоомын хувилбараас хамааран өөрчлөгдөнө. Төслийн тайландаа бодит хэмжилт мэтээр ашиглаж болохгүй.

АШИГЛАХ ЗААВАР
1. temp.html болон temp.css хоёрыг нэг хавтсанд хадгална.
2. temp.html файлыг Chrome эсвэл Edge дээр нээнэ.
3. Үндсэн website-д нэгтгэхдээ энэ хавтсыг бусад HTML хуудсууд байрладаг хавтас руу хуулна.
4. Навигацийн index.html, builder.html, guide.html, fps.html, benchmark.html, compare.html, prebuilt.html, shop.html, catalog.html холбоосууд нь үндсэн website-ийн бусад хуудсууд тухайн хавтсанд байгаа үед ажиллана. Үндсэн төслийн файл нэр өөр бол href утгуудыг тааруулна.
5. Бусад хуудсын цэсэнд <a href="temp.html">Температур</a> холбоос нэмнэ.

ТЕХНИКИЙН ТАЙЛБАР
- HTML болон CSS ашигласан; JavaScript шаардлагагүй.
- Угсралтын мэдээллийг <details>/<summary> ашиглан нээж, хаана.
- Бүх угсралтын дэлгэрэнгүй хүснэгт ижил 1080p (1920×1080), High Settings нөхцөлийг харуулна.
- Дотоод төсвийн холбоосууд тухайн угсралтын хэсэг рүү очно.
- Хуудас нь утас, таблет, компьютерийн дэлгэцэд тааруулсан responsive загвартай.
